# Translations

## Translation Guide 
- Only edit en-editable/common.json
- Follow i18next format when adding new keys
- Keys can be added in any order in en-editable
- don't run scripts unecessarily to save credits

## Local Set Up
- clone repo
- run `npm install`
- run `npm exec tsx ./src/scripts/sortTranslationObjects.ts`

- This will be changed to `main.ts` in the future.
